# zepto-powerbi-analysis
Power BI dashboard analyzing product distribution, pricing, discounts, and stock-out trends

Budget segment dominates (~67%) → mass-market demand
Premium segment is very small → niche category
Meat, Fish & Eggs has highest discounts → perishable strategy
Biscuits & Beverages show high stock-out → high demand
Core categories: Cooking Essentials & Munchies

Tools used : 
Power BI
DAX
MySQL
Excel

Key Metrics 
Total Products
Average Price
Stock-Out Percentage


SQL was used for:
- Data cleaning and transformation
- Creating analytical views
- Performing category and segment-level analysis

Queries available in:
`sql/zepto_analysis_queries.sql`
